# 贪吃蛇游戏 (Snake Game)

一个使用 HTML5 Canvas 开发的经典贪吃蛇游戏，采用霓虹美学风格，支持桌面和移动端。

## 游戏说明

玩家控制一条蛇在网格中移动，吃食物（红色圆点）来增长身体并获得分数。游戏会随着得分增加而加速，难度逐渐提升。撞到墙壁或自己的身体则游戏结束。

## 控制方式

- **桌面端**: 方向键 / WASD 控制方向，空格键开始，P 键暂停
- **移动端**: 滑动屏幕控制方向，点击开始

## 功能特性

- 经典贪吃蛇玩法，20×20 网格
- 霓虹绿色主题，发光视觉效果
- 得分和最高分记录（localStorage 持久化）
- 响应式设计，适配各种屏幕
- 触摸屏支持
