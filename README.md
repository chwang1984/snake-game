# 贪吃蛇游戏 (Snake Game)

一个使用HTML5 Canvas开发的经典贪吃蛇游戏，具有霓虹美学风格和响应式设计。

## 功能特点

### 🎮 游戏特性
- **经典贪吃蛇玩法** - 控制蛇吃食物并避免碰撞
- **得分系统** - 每吃一个食物得10分
- **最高分记录** - 使用localStorage持久化存储
- **难度递增** - 随着得分增加，游戏速度逐渐加快
- **多种游戏状态** - 开始、进行中、暂停、游戏结束

### 🎨 视觉效果
- **霓虹美学风格** - 绿色霓虹主题
- **渐变效果** - 蛇身体使用径向渐变渲染
- **发光边框** - Canvas带有发光边框效果
- **像素字体** - 使用Press Start 2P字体（复古风格）

### 📱 响应式设计
- **自适应画布** - 根据屏幕大小自动调整
- **移动端支持** - 支持触摸屏滑动操作
- **最小尺寸保障** - 保持300px最小可玩尺寸
- **横竖屏适配** - 在不同方向屏幕下正常显示

### 🕹️ 控制方式
- **键盘控制**：
  - 方向键或WASD控制蛇移动方向
  - 空格键：开始/重新开始游戏
  - P键：暂停/继续游戏
- **触摸控制**（移动设备）：
  - 在屏幕上滑动改变蛇的方向
  - 点击开始/重新开始游戏

## 技术实现

### HTML5 Canvas
游戏使用HTML5 Canvas进行渲染，实现了：
- 网格系统（20×20）
- 动态尺寸计算
- 高性能渲染

### JavaScript游戏逻辑
核心逻辑包括：
- 蛇移动算法
- 食物随机生成（不会出现在蛇身上）
- 碰撞检测（墙壁和自身）
- 游戏状态管理

### 响应式设计
- `resizeCanvas()` 函数动态调整画布大小
- 媒体查询优化移动端显示
- 触摸事件处理

### 本地存储
- 使用localStorage存储最高分
- 跨浏览器会话持久化

## 浏览器兼容性
- 支持所有现代浏览器（Chrome, Firefox, Safari, Edge）
- 支持移动设备浏览器（iOS Safari, Android Chrome）
- 需要支持HTML5 Canvas和JavaScript

## 游戏操作说明

1. **开始游戏**：按空格键或点击开始界面
2. **控制蛇**：
   - 使用方向键（↑↓←→）或WASD键控制蛇移动方向
   - 不能直接反向（如向右时不能立即向左）
3. **游戏目标**：
   - 控制蛇吃到红色食物（每次+10分）
   - 避免撞到墙壁或自己的身体
4. **暂停/继续**：按P键
5. **重新开始**：游戏结束后按空格键
